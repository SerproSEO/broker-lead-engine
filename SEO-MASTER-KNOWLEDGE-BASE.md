- **Dwell Time**: Average 2:17 for ranking pages

## 🔍 Keyword Research Mastery

### The Four Types of Search Intent
1. **Informational** (60% of searches)
   - "What is cyber insurance"
   - "How much does business insurance cost"
   - Target with comprehensive guides

2. **Navigational** (10% of searches)
   - "Progressive commercial login"
   - Usually brand-specific, hard to capture

3. **Commercial Investigation** (20% of searches)
   - "Best cyber insurance providers"
   - "Commercial insurance reviews"
   - HIGH VALUE - these convert at 5-8%

4. **Transactional** (10% of searches)
   - "Buy business insurance online"
   - "Get commercial insurance quote"
   - HIGHEST VALUE - 10-15% conversion

### Keyword Research Process

#### Step 1: Seed Keyword Discovery
- **Client Language Mining**: Interview transcripts, support tickets, sales calls
- **Competitor Gap Analysis**: What they rank for that you don't
- **Google Suggest & People Also Ask**: Goldmine for long-tail
- **Industry Forums**: Reddit, Quora, industry-specific forums

#### Step 2: Keyword Metrics Analysis
- **Search Volume**: Minimum 100/month for effort worthiness
- **Keyword Difficulty (KD)**: 
  - 0-30: Easy (target immediately)
  - 31-60: Medium (build authority first)
  - 61-100: Hard (need significant backlinks)
- **CPC Value**: Insurance keywords $20-$200 (indicates commercial intent)
- **Trend Analysis**: Growing vs. declining searches

#### Step 3: Topic Cluster Strategy
**Hub Page Example**: "Commercial Insurance Guide"
- **Spoke 1**: "General Liability Insurance"
- **Spoke 2**: "Professional Liability Insurance"
- **Spoke 3**: "Cyber Insurance"
- **Spoke 4**: "Workers Compensation"
- Internal linking passes 40% of ranking power

### Long-Tail Keyword Strategy
- **Formula**: [Location] + [Insurance Type] + [Modifier]
- Example: "Chicago cyber insurance for tech startups"
- Long-tail converts 2.5x better than head terms
- Less competition, faster rankings

### Semantic SEO & LSI Keywords
- **Primary**: "cyber insurance"
- **LSI Terms**: data breach coverage, ransomware protection, network security liability
- **Entities**: GDPR, HIPAA, SOC 2, PCI compliance
- Use 5-10 LSI terms naturally throughout content

## 📝 Content Optimization Framework

### On-Page SEO Checklist 2025

#### Title Tag Optimization
- **Length**: 50-60 characters
- **Format**: Primary Keyword | Secondary | Brand
- **Power Words**: Best, Guide, 2025, Free, How to
- **CTR Boost**: Numbers increase CTR by 36%
- Example: "Cyber Insurance Cost 2025: Save 40% [Free Calculator]"

#### Meta Description
- **Length**: 150-160 characters
- **Include**: Primary keyword, CTA, value proposition
- **Test**: A/B test can improve CTR by 30%
- Example: "Get cyber insurance quotes in 60 seconds. Compare top providers, save up to 40%. Free consultation for businesses. No obligation."

#### Header Structure
```
H1: One per page, includes primary keyword
  H2: 3-5 major sections, use variations
    H3: Supporting points, LSI keywords
      H4: Detailed subsections if needed
```

#### Content Requirements
- **Word Count**: 
  - Informational: 2,000-3,000 words
  - Commercial: 1,500-2,000 words
  - Transactional: 800-1,200 words
- **Keyword Density**: 0.5-1.5% (don't over-optimize)
- **Readability**: 8th-grade level for B2B content
- **Multimedia**: Images every 300 words, videos increase dwell time 2.5x

### Featured Snippet Optimization
**Paragraph Snippets** (63% of featured snippets):
- 40-50 word answers
- Start with "Insurance type is..."
- Use simple, direct language

**List Snippets** (19% of featured snippets):
- Use numbered or bulleted lists
- 5-8 items optimal
- Each item 10-15 words

**Table Snippets** (16% of featured snippets):
- Compare 3-5 options
- Use HTML tables
- Include pricing when possible

### Internal Linking Strategy
- **Link Velocity**: 3-5 internal links per 1,000 words
- **Anchor Text**: Vary between exact, partial, and branded
- **Link Relevance**: Only link to topically related content
- **Link Position**: Earlier links pass more value

## ⚙️ Technical SEO Requirements

### Site Architecture
- **URL Structure**: /insurance-type/sub-category/page-name
- **Breadcrumbs**: Improve navigation and rankings
- **Sitemap**: XML sitemap updated automatically
- **Robots.txt**: Block duplicate content, admin pages

### Page Speed Optimization
- **Image Optimization**: WebP format, lazy loading, proper sizing
- **Code Minification**: CSS, JavaScript, HTML
- **CDN Implementation**: Reduce server response time
- **Caching**: Browser and server-side caching
- **Goal**: 90+ PageSpeed Insights score

### Mobile-First Requirements
- **Responsive Design**: Test on 5+ devices
- **Touch Targets**: Minimum 48x48 pixels
- **Font Size**: Minimum 16px for body text
- **Viewport Configuration**: Proper meta viewport tag

### Schema Markup Implementation
```json
{
  "@context": "https://schema.org",
  "@type": "InsuranceAgency",
  "name": "Broker Lead Engine",
  "description": "Commercial insurance lead generation",
  "areaServed": "United States",
  "availableChannel": {
    "@type": "ServiceChannel",
    "serviceType": "Commercial Insurance"
  }
}
```

### Crawlability & Indexation
- **Crawl Budget**: Optimize for important pages
- **Canonical Tags**: Prevent duplicate content
- **Hreflang**: For multi-location targeting
- **Index Coverage**: Monitor in Search Console
