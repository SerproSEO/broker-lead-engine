## Content Templates {#templates}

### Blog Post Template Structure

**Title Formula Options:**
- How to [Achieve Desired Outcome] in [Timeframe]
- The Complete Guide to [Topic] for [Industry]
- [Number] Ways to [Solve Problem]
- Why [Common Belief] Is Wrong About [Topic]

**Introduction (150 words):**
```
Hook: Startling statistic or question
Problem: What challenge does the reader face?
Promise: What will they learn?
Credibility: Why should they trust you?
```

**Body Structure:**
```
Section 1: Current State/Problem (20%)
- Industry statistics
- Common mistakes
- Real consequences

Section 2: Solution Framework (50%)
- Step-by-step process
- Best practices
- Tools and resources

Section 3: Implementation (20%)
- Action steps
- Timeline
- Expected results

Section 4: Case Study/Proof (10%)
- Real example
- Results achieved
- Lessons learned
```

**Conclusion with CTA:**
```
Summary: 3 key takeaways
Next step: Specific action
Offer: Relevant lead magnet
```

### Email Newsletter Template

**Subject Line Formulas:**
- [Industry] Insurance Alert: [Specific Change]
- Save $XX,XXX on [Insurance Type]: New Guide
- Case Study: How [Company] Cut Insurance Costs 40%

**Email Structure:**
```
Preview text: Benefit-focused summary

Opening: Personal greeting + value prop

Main content:
- Featured article (200 words)
- 3 additional resources (50 words each)
- Industry news item
- Tool or calculator highlight

CTA: Book consultation or download resource

Footer: Social links + unsubscribe
```
